# Home

**Start here:** [[hot|What's live]] · [[index|Index]] · [[log|Log]] · [[Profile]] · [[Working Preferences]] · [[Setup]]

## How to use it

- **Add something:** drop a file, a clipped article or a pasted note into `inbox/`, then tell any agent "ingest the inbox". For a link, just give the agent the URL.
- **Ask something:** ask an agent a question. It reads the brain first and cites notes.
- **Keep an answer:** say "save that to the brain". It lands in `wiki/answers/`.
- **Tidy up:** "lint the brain" finds dead links, orphans and stale notes.
- **What happened that day:** `journal/<agent>/` has one note per agent per day, with the evidence behind each claim.
- **Look around:** graph view (Ctrl+G) is colored by folder: me, projects, entities, concepts, answers, sources.
